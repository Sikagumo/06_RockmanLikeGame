■このゲームについて




■起動方法

 デバッグ実行：フォルダ内の「AsouRockman_Debug.exe」を実行してください

 公開時実行：フォルダ内の「AsouRockman_Release.exe」を実行してください


■基本操作方法

・W：上移動
・A：下移動
・S：左移動
・D：右移動
・Space：ジャンプ
・Enter：攻撃


■このゲームの独自機能 (!!ここ大事!!)

・プレイヤー系

　当たり判定関数を縦軸と横軸として統合

　八方の当たり判定位置を縦横で構造体化

　壁に当たっている時に落下速度が減少

　上以外の画面外に落下する対策

　落下中にジャンプしていなかったら、空中ジャンプが可能

　2段階ジャンプを実現(Player.h/MAX_JUMPの定数でジャンプ回数は増やせる)


・その他

　プログラムスクリプトを"Script"フォルダで管理

　インクルードディレクトリを割り当て

　デバッグ時のテキスト・処理を公開ビルド時は描画・処理を行わないようにする
